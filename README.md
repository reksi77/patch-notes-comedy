One line, one bug, one very late night: a patch note for the human brain's habit of replaying your most embarrassing moment from 2017 in 4K at 2 a.m. — with full director commentary — instead of letting you sleep. Written as a real changelog entry for make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty, where the funniest one-line patch note for a bug in real life or human biology wins.

## Run it

```sh
node main.ts
```

This writes the patch-note line to `/output/entry.txt` (153 characters, single line), reads it back, and verifies it byte-for-byte.
